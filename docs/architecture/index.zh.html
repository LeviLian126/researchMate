运行时和恢复流程

运行时流程和故障归属

8 月 16 日免费层边界：可选 Wiki 增强现在使用独立的 30 秒 Provider 超时并在失败时回退原始分块。Dispatcher 同时发布 Worker 就绪心跳，移除一个常驻 Python 进程，为 512 MB 合并服务上的 LangGraph 执行保留内存。
1 · 异步文档摄取和删除 已认证 DOCX 生产路径通过
预留 + 上传FastAPI 验证所有权、类型、大小和配额；浏览器通过带认证的同源 API 代理将字节流写入私有 S3 兼容存储，并由服务端派生对象键、复核声明与实际大小。
提交 + 分发Postgres 原子性地写入文档、任务和发件箱意图；SKIP LOCKED 分发器发布确定性 Celery 任务 ID，带退避和过期声明恢复。
解析 + 索引受租约保护的任务检查字节/校验和，保留嵌套 DOCX 章节来源，替换确定性块行，upsert 命名的稠密+稀疏 Qdrant 向量，并编译 LLM Wiki 页面（短文档 ≤4000 tokens 完全替换；长文档追加概览页面）。
删除 + 收敛删除消费者使用确定性标识符和重试，在数据库子记录之前移除 Qdrant/对象存储投影。托管服务崩溃、毒工作、过期向量和部分删除收敛测试仍待完成。
8 月 9 日生产证据：37.0 KB 合成 DOCX 经 Vercel、Render、私有对象存储、Upstash、worker、Postgres 和 Qdrant v3 在 44.4 秒内达到 ready。扫描 PDF OCR 仍不在已验证边界内。
2 · 证据审查 Agent 持久化 checkpoint 恢复已实测 · Provider 未验证
规划LangGraph 图和 SQL 领域代码分解目标并记录图/流水线版本。
检索 + 提取已实现发送扇出、选定文档的 Qdrant 过滤器、可选 Tavily 检索、服务端拥有的证据 ID 和 schema 验证的声明提取。
预算 + 计量每次模型调用原子性地预留保守上限，拒绝过大的提示，并记录提供商 token、延迟和配置价格估算。
协调 + 审查关系协调和中断/恢复决策代码暴露支持、矛盾、重复、缺口以及批准/编辑/拒绝。
恢复 + 刷新过期的工作流租约拒绝重复交付；持久化检查点恢复时不重放初始输入。变更文档刷新复制未受影响的段落并事务性地发布新版本。
实测边界：线上运行 31947882320 跨越 20 次进程重启恢复 1000/1000 个 PostgreSQL checkpoint，单侧 95% 置信下界为 99.7009%。确定性领域隔离验证 checkpoint 持久性；Qdrant/Provider 执行和托管增量刷新仍未验证。
3 · 评估和可靠性 RAGAS 导入 + 预算/故障代码 · 外部执行未验证
预留在每个用例之前，运行器原子性地针对运行上限预留保守估算；这是调度器防护，不是提供商计费。

Postgres + SQLAlchemy + Supabase migrations + RLS两个 JWT 主体独立写入/读取；API 隐藏通过持久关系事实、事务、schema 演进、多用户隔离和审计。声明、引用、关系、报告、运行、决策和评估需要完整性和连接。证明直接 RLS 拒绝，然后测试事务、并发、备份和恢复。关系模型或运营成本不再适合测量的访问模式。
GitHub OAuth App through Supabase Auth已验证实时回调和双用户项目隔离无需部署另一个身份服务的免费第三方登录。Supabase 仍是 JWT 签发者，不可变的 sub UUID 仍是租户键；GitHub 仅提供认证。证明会话过期/撤销、同邮箱账户关联、直接 RLS 和对象/向量租户隔离。GitHub 取消免费 OAuth 访问或 Supabase 提供商行为无法保持所需的身份/隔离合约。
NVIDIA NIM + OpenAI-compatible SDK适配器已实现；提供商未验证模型驱动的接地合成和流式传输，无需将领域代码耦合到供应商响应对象。证据审查需要在有界证据上进行结构化声明和合成；确定性模板仅保留为单元测试/本地回退。开发提供商冒烟测试、超时/错误映射、结构化输出有效性、忠实度、token/成本和模型版本评估。更小的模型或另一个 OpenAI 兼容端点满足已接受的质量/延迟/成本边界。
Tavily server-side search适配器已实现；提供商未验证当单个 Web 选项启用时添加有界的当前 Web 证据，不向浏览器暴露凭据。相同的排序和上下文打包边界必须比较当前外部证据与已就绪的本地文档。后端凭据冒烟测试、503/错误映射、来源、速率/成本控制、超时/断路行为、注入审查和结果质量测试。Web 证据从已接受场景中移除，或另一个提供商更简单地满足相同有界合约。
Supabase Storage + resource-aware parsing文本层 PDF 生命周期已通过；OCR 仍不可用私有源字节、低内存 PDF 文本提取和结构化 Office 页面/幻灯片/表格提取。Render Free 提供 512 MB；视觉优先的 Docling PDF 解析超出了该边界。生产环境现在默认使用 pypdf，保留页面锚点，并对扫描版 PDF 报告 PARSER_TEXT_LAYER_NOT_FOUND，而非静默调用重型解析器。度量 PDF 延迟和内存，从 pypdf-only 镜像中移除未使用的 Docling 模型下载，验证 DOCX/PPTX 生产路径，并将 OCR 设计为独立的有界 worker 或外部服务。免费 OCR 服务或更大的隔离 worker 满足相同的隐私、引用、延迟和成本合约。
路由式 Hybrid retrieval + dual rerankWiki-guided Hybrid RAG 已上线；五类分路由生产问题通过Wiki 引导的混合 RAG，含 LLM Wiki 编译和 Wiki 优先路由。五条可观测路由选择全文、词法优先精确、dense 优先语义、平衡 Hybrid 或有界扩展 Hybrid。短文档（≤4000 tokens）编译为结构化 Wiki 页面；长文档追加 Overview Wiki 与 Qdrant RAG 块并行。LLM Wiki 编译在向量检索之上提供导航层，用于概览和摘要查询。小型且相关的语料适合全文；大语料必须显式路由，避免精确标识符输给 embedding，也避免同义改写输给词法不匹配。每个 prefetch 与最终查询重复 owner filter；多个改写共享固定分支预算；规划器/向量失败显式降级；结构感知 chunks 保存章节路径与偏移。五块 checksum 影子回放先于 v3 切流，旧集合保留用于仅配置回滚。已认证 Chrome 验收正确处理精确、同义改写、复合、追问和未知预算拒答，并显示章节引用；Render Free 端到端单轮为 27.2–37.2 秒。分路由评估或延迟分布表明无质量收益，或 v3 资源成本超出预算。
Celery + Upstash Redis摄取/工作流/评估/故障任务代码；消息代理未验证并行解析、提取、刷新、评估、有界故障模拟、重试、速率限制和进度。任务比 HTTP 请求存活更久，需要有界扇出和独立重试。将受保护的 Redis 配置转移到 Render；证明真实的至少一次交付、队列深度扩展、毒工作、重启、配额、预算和故障过期行为。托管工作流服务满足相同的重试和可观测性合约，且不损失学习价值。

无重复应用部署直接仓库构建、直接 OTLP 导出和合并演示容器以更少活动部件覆盖当前发布边界。当前计划保留一个 Web 部署和一个合并后端服务。满足冻结拓扑的重新开启触发条件，且替代方案在实现前在此记录。
