项目目的

作品集范围

作品集目标

展示 AI 全栈架构、持久化工作流、检索质量、数据合约、可观测性、故障恢复、安全边界和 CI/CD，并提供面试官可检查的证据。

明确不在目标范围内

客户获取、收入、定价、订阅、计费、CRM、营销自动化和增长分析不是成功标准，不会驱动路线图。

如何使用这些文档：招聘者可以审阅项目范围，工程师可以检查链接的合约和证据，demo 用户可以操作系统行为。项目不包含商业转化漏斗。

主要工程场景

从来源集合到可审计的证据报告

主要场景需要长时间运行的摄取、并行证据工作、有状态审查、增量重计算和可测量的质量。这些需求定义了目标架构。

01 / 摄取构建来源语料库上传数十到数百个文档和 Web 来源；异步解析、去重、版本化、分块和索引。
02 / 规划分解研究目标LangGraph 将宽泛问题转化为有界子问题，并持久化 checkpoint 以支持中断和恢复。
03 / 提取构建证据模型Celery worker 并行检索，提取声明，附加页面级引用，并分类支持、冲突、重复和缺口。
04 / 审查解决不确定性低置信度结论、不可信 Web 证据和 prompt-injection 信号暂停等待明确的人工决策。
05 / 综合发布和更新报告生成引用报告，并在语料库变更时仅重计算受影响的声明和章节。
06 / 验证评估系统比较检索和流水线版本；检查 trace、延迟、token、成本、重试、故障和恢复。
