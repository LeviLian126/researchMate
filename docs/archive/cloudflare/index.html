Archived Cloudflare deployment alternative

This page records a superseded hosting option. It is historical context, not an executable recommendation. The current topology is Vercel Hobby plus one combined Render Free service.

Historical boundary

Historical scope

Proposed responsibility

An OpenNext bundle on Cloudflare Workers was considered as a second host for the deterministic browser-only Next.js demo.

Never a backend host

The plan never ran the Python FastAPI, Celery, dispatcher, Docling, or durable workflow processes. Those responsibilities require the combined container runtime selected later.

Historical evidence: the Worker bundle passed repository-side build checks, but release run #4 stopped at provider authorization. No workers.dev endpoint or public Cloudflare deployment was verified.

Decision rationale

Retirement decision

Duplicate surfaceVercel already serves the bounded public web demo, so a second frontend host adds deployment count without backend proof.
Wrong runtimeThe Python API, worker, dispatcher, and parser workload require a container host.
Extra authorization and cost boundaryThe attempted release introduced another provider permission path, while object storage was already available through Supabase.
Smaller frozen topologyDirect Render repository builds remove the need for a duplicate frontend deployment and intermediate image registry.

Repository state

Archived source and residual compatibility

Retired on 26 July 2026: the executable GitHub workflow, application-level OpenNext/Wrangler configuration, Cloudflare npm commands, and deployment dependencies were removed from their active locations. Exact source snapshots remain only in this archive and cannot be triggered by GitHub Actions or npm workspace commands.

Legacy environment-variable aliases and contract literals such as r2_object_key or r2_failure remain for migration and API/data compatibility. They do not select Cloudflare in the current topology. Any later cleanup must update the corresponding migrations, schemas, clients, and tests deliberately.
