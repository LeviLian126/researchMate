Monorepo 结构

项目整体结构

ResearchMate 是一个 monorepo(单仓库多项目),用 npm workspaces 管理 JavaScript/TypeScript 包,用 uv workspace 管理 Python 包。所有代码、配置和文档在同一个 Git 仓库中。

什么是 monorepo? monorepo 是一种将多个相关项目放在同一个版本控制仓库中管理的策略。优势是共享配置、统一版本锁定、跨项目重构更方便。ResearchMate 的前端(apps/web)、后端 API(apps/api)和 AI Worker(workers/ai-worker)都在同一个仓库里。
apps/web/
Next.js 前端应用,部署在 Vercel。包含页面路由、React 组件、API 客户端和认证逻辑。
apps/api/
FastAPI 后端 REST API,提供 45 个 /api/v1 操作。包含路由、Pydantic 模型、服务编排和 PostgreSQL 持久化层。
workers/ai-worker/
Celery Worker + Outbox Dispatcher,负责文档解析、向量索引、LangGraph 工作流和评估。与 API 合并部署在同一个 Render 容器。
packages/shared/
前后端共享的 TypeScript 类型契约(contracts.ts),定义 API 数据形状的权威来源。
infra/
基础设施配置:Supabase SQL 迁移文件、Qdrant 集合配置、OpenAPI 规范。
scripts/
运维脚本:数据库迁移执行器、Qdrant rerank 回填、OpenAPI 导出等。
tests/
Python 测试套件(36 个文件),覆盖单元测试、HTTP 集成测试、契约检视和发布安全。
docs/
浏览器可打开的项目文档(HTML),即你正在查看的页面。
.github/workflows/
GitHub Actions CI 流水线定义(ci.yml)。
skill/
gstack 开发技能库,包含 land-and-deploy、qa、review 等工作流技能。
npm workspaces(Node.js 包管理)

根 package.json 声明 "workspaces": ["apps/web", "packages/shared"]。所有 JS/TS 依赖由根级 package-lock.json 统一锁定,前端和共享包通过 workspace 协议互相引用。

uv workspace(Python 包管理)

根 pyproject.toml 声明 [tool.uv.workspace] members = ["apps/api", "workers/ai-worker"]。所有 Python 依赖由 uv.lock 统一锁定,CI 和 Docker 中用 uv sync --frozen 严格按锁文件安装。

全链路切片

一个 Ask 请求的完整旅程

从用户在浏览器输入问题,到收到带引用的回答,请求经过的全部文件和模块:

浏览器chat-composer.tsx,use-chat-workspace.ts,api.ts(apiFetch + getAccessToken),supabase.ts(JWT),fetch()
FastAPI 中间件main.py:CORS,attach_request_id(生成 request_id + 安全 headers)
认证 + 依赖注入dependencies.py:get_current_user(JWKS 验证 JWT),get_store / get_chat_provider / get_hybrid_store / get_reranker(从 app.state 读取单例)
路由 + 幂等routers/ask.py(极薄编排),services/idempotency.py(四态机:execute / replay / mismatch / in_progress)
对话 scopeservices/query_conversation.py:验证项目/对话,加载 chunks,query_context.py(摘要压缩 + token 预算 + 跨对话 memory)
路由式 Hybrid 检索query_planning.py 选择全文、精确、语义、hybrid 或扩展 hybrid；Qdrant v3 执行命名 BM25 + NVIDIA 4096 维 dense 分支，以路由权重 RRF 融合并强制 owner filter。
Rerankservices/rerank.py:Qdrant native,NVIDIA ranking,Deterministic(三路降级),pack_chunks(token 预算打包)
答案生成services/query_generation.py,answering.py:有证据走 LLM grounded(JSON schema 验证 + 一次修复);无证据走 chat 或 abstain
持久化 + 响应store.py / persistence/postgres.py(RLS 参数):保存 run/trace/消息,返回 AskResponse,中间件附加 headers,浏览器渲染
异步路径:文档上传后,API 写 outbox_events,dispatcher 轮询分发,Celery worker 摄取(parse + chunk + vector),Qdrant 就绪。用户下次 Ask 时检索到新文档的证据。这条异步链路经过 dispatch_outbox.py,tasks.py,ingestion_service.py,parsing.py,ingestion_projections.py,qdrant_store.py。
