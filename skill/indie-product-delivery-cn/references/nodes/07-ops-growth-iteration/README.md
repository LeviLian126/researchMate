# 运维、学习与迭代

## 阅读相关 workflow

| 需求 | 阅读 |
|---|---|
| 回顾已发布的内容、验证信号、评估健康度，并区分事件与学习 | `production-health-and-signal-integrity.md` |
| 整合客户价值、选择实验或下一个切片，并保留决策记录 | `customer-evidence-experiments-and-next-slice.md` |

所选 workflow 中每条适用的要求都是最低交付标准，因为它们确保运营决策与真实信号挂钩。仅当某项检查确实无关时才可跳过。当有助于回答当前运营问题时，可添加分析、调查或行动；当所需密钥、API 凭证或环境不可用时停止。

## 输出契约

返回观察到的产品/生产状态、证据与置信度、客户或运营信号、事件或学习的解读、下一个决策或切片、其负责人，以及应触发重新进入的触发条件或证据。不要暗示超出实际收集证据范围的背景监控。
