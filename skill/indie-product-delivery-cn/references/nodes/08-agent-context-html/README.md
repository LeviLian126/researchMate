# HTML Agent 上下文与项目看板

当任务涉及实现、维护、评审或文档撰写时，使用此节点处理位于项目 `docs/` 下的默认 HTML 项目看板。该看板是当前产品、架构、代码、证据与发布事实的持久可视化上下文。普通 Markdown 仍可在其他位置编辑，但看板始终是项目的默认记录。

| 需求 | 阅读 |
|---|---|
| 判断 HTML 是否是合适的媒介并遵循看板 workflow | `html-medium-and-workflow.md` |
| 定义页面、证据类别、项目拓扑、台账、状态与历史 | `project-board-content-and-evidence.md` |
| 构建视觉系统、图表、交互、响应式行为与可访问性 | `visual-interaction-and-accessibility.md` |
| 验证内容真实性、链接、HTML、浏览器行为与交接 | `validation-and-handoff.md` |

仅当 `assets/document-system.css` 的面向文档的系统契合该仓库时，才以其作为起点。现有项目样式与用户明确的引用优先级更高。

## 输出契约

在项目常规 `docs/` 位置下返回看板路径、已更新的页面或区域、已核查的来源事实与证据、状态/决策变更、实际运行的确定性与浏览器验证、剩余的未知项或冲突，以及下一步行动。让看板始终作为当前证据面；当适用时，将历史细节保留在其链接的活动记录中。
