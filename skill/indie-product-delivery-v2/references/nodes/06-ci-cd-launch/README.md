# Release Execution

Use this when the present need is deploying, rolling out, migrating, or recovering: release readiness, pipeline/CI gates, executing an authorized rollout, post-deploy smoke/watch, or the release record.

| Need | Read |
|---|---|
| establish target, source, authorization, environment, pipeline, credentials, and release readiness | `release.md` — Readiness and environment |
| execute an authorized rollout, migration, provider action, recovery, smoke/watch, and release record | `release.md` — Rollout, recovery, and record |

Shared status codes (`READY_TO_EXECUTE` etc.) and severity routing live in `references/methods.md`.
