# Frontend Build

Use this when the present need is a frontend surface: its journey, hierarchy, content, and complete states; visual direction, prototype, or redesign; production components, responsiveness, accessibility, motion; or browser proof and visual debugging.

| Need | Read |
|---|---|
| recover the surface; design its journey, hierarchy, content, and full states | `frontend.md` — Experience and content |
| set visual direction, translate references/prototypes, or redesign | `frontend.md` — Visual direction |
| build production components, responsiveness, accessibility, motion; verify in a browser | `frontend.md` — Build and proof |
| write long-form help or explanation inside a frontend surface | `references/docs.md` |

Shared mechanisms (fact states, reuse/extend/replace/new) live in `references/methods.md`.
