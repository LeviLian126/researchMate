# Market and MVP Scope

Use this when the present need is product-side: who the product serves, what it promises, whether it's worth building, how to price or position it, and what the smallest credible first slice is.

| Need | Read |
|---|---|
| recover product truth, calibrate ambition, cut an MVP/MAP, write acceptance, or control a changed requirement | `market-and-scope.md` |
| validate demand, alternatives, pricing, distribution, positioning, or public trust and visual meaning | `market-and-scope.md` |

One file serves both — jump to the section that matches the present question. Several mechanisms used here (fact states, confidence thresholds, reuse decisions) are defined once in `references/methods.md`.
