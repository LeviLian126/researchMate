# Market and MVP Scope

## Read the relevant workflow

| Need | Read |
|---|---|
| recover decisions, calibrate ambition, challenge the premise, or decide which unknowns need research | `product-discovery-and-decisions.md` |
| cut scope, define the narrow slice, write acceptance, control a changed requirement, and hand off to system design | `mvp-scope-acceptance-and-handoff.md` |
| validate demand, alternatives, pricing, distribution, positioning, trust, or public visual meaning | `market-validation-positioning-and-trust.md` |

Read only the workflow or workflows that materially affect the result. Use `../08-agent-context-html/README.md` when product truth must become durable HTML project documentation.

## Output contract

Return the smallest decision-ready product handoff: user/problem/promise, first-success
journey, kept/deferred/rejected scope, acceptance criteria, non-goals, assumptions and
open decisions, relevant evidence, and one state: `Ready`, `Ready with named risks`,
`Blocked`, or `Fast-track accepted`. Route only the unresolved question that belongs to
another node.
