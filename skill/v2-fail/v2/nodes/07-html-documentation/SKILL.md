# HTML documentation — draft skeleton

## Questions this node must settle

- Who reads the artifact and what decision or handoff must it support?
- Which relationships are spatial, comparative, interactive, or stateful?
- Can the artifact be one self-contained HTML file with no build step?
- Are provenance, verification state, unknowns, dates, and current release identity visible?
- Does it remain readable, accessible, printable, and useful without JavaScript?
