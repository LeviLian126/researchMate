# Frontend — draft skeleton

## Questions this node must settle

- What user outcome and information hierarchy does the screen support?
- Which states exist before, during, after, and when an operation fails?
- Does the design have a deliberate visual direction without sacrificing usability?
- Do keyboard, focus, contrast, narrow viewport, latency, and recovery paths work?
- Does the browser call the current public contract rather than a stale mock?
