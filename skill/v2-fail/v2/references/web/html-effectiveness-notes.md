## Why it matters

The corpus demonstrates when a self-contained HTML artifact is more useful than linear Markdown: side-by-side exploration, annotated code review, design-system contact sheets, interactive prototypes, diagrams, slide decks, explainers, status/incident reports, and small editing interfaces that export the user's decisions.

## Principles to carry forward

- Choose HTML because spatial layout or interaction improves comprehension.
- Prefer a self-contained file with no install or build step for durable handoff artifacts.
- Make the artifact actionable: comparison, navigation, filtering, editing, or export should support a real decision.
- Keep source status, unknowns, and evidence visible; polished presentation must not blur verification boundaries.
- Retain accessible semantic structure and a useful static/print fallback.

The complete upstream text and all 20 example HTML files are vendored under the Apache-2.0 license, and the homepage's readable text is also transcribed to Markdown, so later synthesis does not depend on the external site remaining available.
