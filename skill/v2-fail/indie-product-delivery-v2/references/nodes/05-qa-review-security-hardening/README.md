# Quality Gate

Use this when the present need is a quality, review, or security judgment on a change: scoping what to review, running the right proof, reading the diff/contract, or issuing the ship/hold decision.

| Need | Read |
|---|---|
| establish acceptance, evidence depth, review base, and diff/contract findings | `quality.md` — Scope and review |
| plan runtime/browser, reliability, compatibility, security, or privacy proof with the right authority | `quality.md` — Proof |
| reconcile evidence and issue the quality or release-readiness decision | `quality.md` — Decision |

Shared mechanisms (fact states, evidence quality, status codes, severity routing) live in `references/methods.md`.
