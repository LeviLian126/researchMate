# HTML Agent 上下文与项目看板

当任务涉及实现、维护、评审或文档时，使用此节点来处理项目 `docs/` 下的默认 HTML 项目看板。该看板是当前产品、架构、代码、证据和发布事实的持久可视化上下文。普通 Markdown 仍可在其他地方编辑，但看板仍是默认的项目记录。

| 需求 | 阅读 |
|---|---|
| 决定 HTML 是否是正确的媒介并遵循看板 workflow | `html-medium-and-workflow.md` |
| 定义页面、证据类别、项目拓扑、台账、状态和历史 | `project-board-content-and-evidence.md` |
| 构建视觉系统、图表、交互、响应式行为和可访问性 | `visual-interaction-and-accessibility.md` |
| 验证内容真实性、链接、HTML、浏览器行为和交接 | `validation-and-handoff.md` |

仅当 `assets/document-system.css` 的面向文档的系统适合该仓库时，才从它开始。现有项目样式和明确的用户引用优先。

## 输出契约

返回看板在项目常规 `docs/` 位置下的路径、已更新的页面或区域、已检查的来源事实和证据、状态/决策变更、实际运行的确定性和浏览器验证、剩余的未知项或冲突，以及下一步行动。保持看板作为当前证据面；当适用时，将历史细节保留在其链接的活动记录中。
